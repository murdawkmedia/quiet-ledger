# Security

Use fictional data while evaluating this experimental build. Never include
credentials, seeds, financial records or browser messaging state in a public
issue. Use GitHub Security → Report a vulnerability for private disclosure when that
feature is available. Otherwise open an issue requesting a private contact route
without publishing the vulnerability or working access capabilities. Public reports should use
synthetic reproductions and omit working access capabilities.

Report the affected version, relevant component, expected behavior and a minimal
synthetic reproduction. A listed provider or passing fixture test is not a claim
of real funded-payment acceptance. Keep independent backups before upgrading.
