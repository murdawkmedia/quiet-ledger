# Contributing

Use the canonical ngit/GitWorkshop repository for primary development. GitHub is
an exact mirror; changes accepted there must be reconciled to the canonical refs.
Keep changes focused and describe the problem, behavior and relevant verification.
Use fictional fixtures. Money, authorization and isolation changes require tests.
Never submit runtime databases, secrets, keys, customer records or private paths.
Preserve upstream license notices and attribution. Contributions are licensed
under AGPL-3.0-or-later, consistent with this repository's license.
